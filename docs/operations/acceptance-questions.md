# Preguntas de aceptación

1. ¿Qué función recibe los mensajes MIDI en la aplicación principal?
2. ¿Qué funciones participan en la conexión MIDI por red?
3. ¿Dónde se crean y mantienen las salas del relay?
4. ¿Qué función abre la salida secundaria?
5. ¿Qué código construye el flujo de `captureStream`?
6. ¿Qué función compone cada cuadro y qué estado consume?
7. ¿Qué componentes dependen de Web MIDI?
8. ¿Qué funciones administran la caché IndexedDB para reversa?
9. ¿Qué cambio podría afectar simultáneamente render, pistas y salida secundaria?
10. ¿Qué módulos del relay o emisor podrían reutilizarse sin depender del compositor?

Las respuestas y su evidencia se registran en `graphify-validation.md`; el grafo orienta la búsqueda y el código confirma la conclusión.
